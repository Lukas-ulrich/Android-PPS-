# Android-PPS-
Eine Android-App, mit der bestimmte Kontakte selbst im Ruhemodus weiterhin Benachrichtigungen und Anrufe durchlassen können. Nutzer können auswählen, welche Kontakte trotz aktivem Ruhemodus weiterhin:  anrufen dürfen, Nachrichten senden können, oder Benachrichtigungen auslösen dürfen.
